# Запрошення на весілля — Ігор та Марічка

React + Vite, структура наближена до MVC:

```
src/
  models/         M — чисті дані (weddingData.js): імена, дата, локація, палітра
  controllers/    C — логіка/поведінка як хуки:
                      useCountdown.js    — live зворотний відлік
                      useScrollReveal.js — IntersectionObserver для fade-in анімації
                      useVenue.js        — компонує reveal + посилання на карту для Venue
  views/          V — компоненти, які тільки рендерять пропси:
                      Hero.jsx, Greeting.jsx, Venue.jsx, DressCode.jsx, icons.jsx
  App.jsx         композиційний корінь — збирає 4 секції в порядку скролу
  index.css       глобальні стилі, scroll-snap, анімації
```

Чиста react тут не має "контролерів" у класичному MVC-сенсі, тож роль
контролера виконують кастомні хуки: вони містять усю логіку (таймер,
спостереження за скролом) і віддають views лише готові значення. Views
самі нічого не рахують — тільки рендерять те, що прийшло з моделі й
контролерів.

## Запуск

```bash
npm install
npm run dev       # локальний сервер розробки
npm run build      # продакшн-збірка у dist/
```

## Що змінити

- **Текст, дату, локацію, кольори дрес-коду** — усе в `src/models/weddingData.js`.
- **Фото пари** — замінити `src/assets/couple-photo.jpg` на своє (той самий файл-неймінг, або онови імпорт у `Hero.jsx`).
- **Час до події** — `wedding.date.iso` у моделі; відлік і "початок церемонії" підхоплять зміну автоматично.
